# Résonance Citoyenne - Brand Style Guide

> **Mission**: Faire résonner la voix de chaque citoyen à travers une démocratie directe participative et accessible.

## Brand Identity

### Brand Essence
**Résonance Citoyenne** n'est pas une plateforme de vote, c'est un **mouvement citoyen**. Chaque voix compte, chaque vote fait vibrer la démocratie. Nous ne sommes pas un site gouvernemental froid, nous sommes la **place publique numérique** où les citoyens se rassemblent, débattent, et font entendre leur voix.

### Brand Values
1. **Chaleur Humaine** - Convivialité, accueil, "à la bonne franquette"
2. **Transparence Totale** - Votes anonymes mais résultats visibles
3. **Accessibilité Universelle** - De 18 à 100 ans, tous niveaux numériques
4. **Résonance Collective** - Connexion, vibration, mouvement ensemble
5. **Confiance Démocratique** - Sécurité, intégrité, légitimité

### Brand Personality
- **Chaleureux** plutôt que froid
- **Accessible** plutôt que technique
- **Engageant** plutôt que administratif
- **Vivant** plutôt que statique
- **Authentique** plutôt que corporate

### Tone of Voice
**Tu** (pas "vous") - Friendly, proche, comme un ami
**Direct** - Pas de jargon, langage simple
**Encourageant** - "Rejoins-nous !", "Ta voix compte !", "Faisons résonner ça ensemble"
**Optimiste** - Croire en la démocratie participative

**Exemples:**
- ✅ "Rejoins l'Agora et fais entendre ta voix"
- ❌ "Inscrivez-vous pour accéder à la plateforme de vote"

#### Typography Best Practices

✅ **DO:**
- Use Fraunces for emotional impact (headings, hero, numbers)
- Use Inter for readability (body, UI, forms)
- Use Caveat sparingly (quotes only)
- Maintain 1.6 line-height for body text (readability)
- Keep body text minimum 16px (accessibility)
- Use semibold/bold for emphasis, not color alone
- Left-align text (French reading direction)

❌ **DON'T:**
- Mix too many font weights (stick to 400, 600, 700)
- Use Caveat for UI elements or buttons
- Use text smaller than 12px
- Use low-contrast text (always check WCAG AA)
- Use ALL CAPS for long text (readability issue)
- Center-align long paragraphs (hard to read)

### Spacing System (8px Grid)

```
Spacing Scale:
xxs: 4px   (0.25rem) - Tight internal spacing (icon padding)
xs:  8px   (0.5rem)  - Component internal (badge padding)
sm:  12px  (0.75rem) - Small gaps (between elements)
md:  16px  (1rem)    - Default spacing ⭐ Most common
lg:  24px  (1.5rem)  - Section spacing (card padding)
xl:  32px  (2rem)    - Major sections (between cards)
2xl: 48px  (3rem)    - Page sections (hero to content)
3xl: 64px  (4rem)    - Hero spacing (large breathing room)
4xl: 96px  (6rem)    - Extreme spacing (rare, homepage only)

Component Spacing Examples:
- Button padding: 12px 24px (sm horizontal, lg vertical)
- Card padding: 24px (lg)
- Card gap: 16px (md)
- Input padding: 12px 16px
- Section margin: 48px (2xl)
```

### Border Radius (Organic Shapes)

```
Small:  8px  - Inputs, small buttons, badges
Medium: 12px - Cards, most components ⭐ Default
Large:  16px - Modals, hero cards
XL:     24px - Special feature cards (rare)
Full:   9999px - Pills, avatar, circular badges

Never use 0px (sharp corners) except for specific design intention
```

### Shadows (Soft & Organic)

```
None: none
  Usage: Flat elements, backgrounds

Soft: 0 2px 8px rgba(0, 0, 0, 0.08)
  Usage: Default cards, resting state
  Effect: Subtle, paper-like

Medium: 0 4px 16px rgba(0, 0, 0, 0.12)
  Usage: Hover state, lifted elements
  Effect: Noticeable elevation

Large: 0 8px 24px rgba(0, 0, 0, 0.16)
  Usage: Modals, dropdowns, important UI
  Effect: Strong elevation

Orange Glow: 0 0 0 3px rgba(255, 107, 53, 0.1)
  Usage: Focus state on interactive elements
  Effect: Warm, accessible focus indicator

Avoid hard shadows (0 4px 4px) - too harsh
Avoid pure black shadows - use rgba(0,0,0,0.08-0.16)
```

### Photography & Imagery

**Style:**
- **Authentic citizen photos** (real people, not stock photos)
- **Diverse representation** (all ages, origins, backgrounds)
- **Black & white with orange tint** for hero images
- **Hands raised, assemblies, gatherings** (resonance metaphor)
- **Warm lighting** (golden hour, not harsh studio)

**Avoid:**
- Cold, corporate stock photos
- Staged, overly professional shots
- Models that look "too perfect"
- Empty spaces with no human connection

**Image Treatment:**
```css
/* Hero images: B&W with orange overlay */
filter: grayscale(100%);
mix-blend-mode: multiply;
overlay: linear-gradient(135deg, rgba(255,107,53,0.3), transparent);

/* Card images: Slight warm tint */
filter: sepia(5%) saturate(110%);
```

## Animation Guidelines

### Timing
```
Fast: 150ms
  - Hover states
  - Button presses
  - Focus indicators

Normal: 250ms ⭐ Most common
  - Card transitions
  - Modal appearances
  - Drawer slides

Slow: 400ms
  - Page transitions
  - Complex animations
  - Multi-step reveals
```

### Easing Functions
```css
/* Default - Material Design standard */
ease-default: cubic-bezier(0.4, 0.0, 0.2, 1)

/* Entrance - Deceleration curve */
ease-in: cubic-bezier(0.0, 0.0, 0.2, 1)

/* Exit - Acceleration curve */
ease-out: cubic-bezier(0.4, 0.0, 1, 1)

/* Spring (for playful interactions) */
spring: cubic-bezier(0.34, 1.56, 0.64, 1)
```

## Accessibility Checklist

- [ ] All text meets WCAG AA contrast (4.5:1 minimum)
- [ ] Touch targets minimum 44x44px
- [ ] Keyboard navigation works for all interactive elements
- [ ] Focus indicators clearly visible (2px orange outline)
- [ ] ARIA labels on icons and interactive elements
- [ ] Alt text on all images
- [ ] Semantic HTML (`<nav>`, `<main>`, `<button>`)
- [ ] Form labels associated with inputs
- [ ] Error messages clear and helpful
- [ ] Respects `prefers-reduced-motion`
- [ ] Text resizable to 200% without breaking layout
- [ ] No reliance on color alone (icons + text)
- [ ] Screen reader tested

## Do's and Don'ts

### ✅ DO:
- Use warm, organic colors (orange, honey, forest green)
- Use Fraunces for emotional moments (headings, big numbers)
- Use Inter for readability (body, UI)
- Maintain generous white space
- Use real photos of citizens, diverse representation
- Write in friendly "tu" form
- Prioritize accessibility in every decision
- Test on real devices (especially older phones)
- Show empathy and warmth in microcopy

### ❌ DON'T:
- Use cold colors (pure blue, gray-only palettes)
- Use corporate stock photos
- Use jargon or administrative language
- Cram too many elements together
- Use text smaller than 12px
- Rely on color alone to convey meaning
- Create inaccessible contrast ratios
- Use animations that can't be disabled
- Use harsh, geometric shapes (prefer organic)
- Speak like a government form ("Veuillez valider votre choix")
